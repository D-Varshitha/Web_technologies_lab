findOne() → returns the actual document.
insertOne() → returns an operation result; insertedId gives the new document's ID.
updateOne() → matchedCount = documents found; modifiedCount = documents actually changed.
deleteOne() → deletedCount = documents deleted.
deletedCount = 0 does not mean MongoDB failed; it means no document matched.
insertedId is useful for sending the newly created post's ID back to React.
MongoDB operation results tell Express what happened, allowing Express to return the appropriate HTTP status.
